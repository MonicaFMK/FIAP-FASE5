# Tech Challenge – Fase 5

Projeto desenvolvido para o Tech Challenge da Fase 5 da FIAP.

O objetivo é analisar os dados da ong Passos Mágicos e responder as 10 perguntas do trabalho utilizando python e power BI e disponibilizar uma aplicação interativa desenvolvida com Streamlit.
